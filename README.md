# 🚀 Person Management System (Full-Stack)

A modern, full-stack web application designed for efficient management of personal records. Built with a robust **ASP.NET Core Web API** backend and a responsive **React** frontend styled with **Tailwind CSS**.

---

### 🛠️ Tech Stack

**Backend**
* **Framework:** ASP.NET Core Web API (.NET)
* **Language:** C#
* **Database & ORM:** SQLite / Entity Framework Core
* **Architecture:** Controller-driven API with DTOs and CORS policy configuration

**Frontend**
* **Framework / Build Tool:** React.js (Vite)
* **Styling:** Tailwind CSS
* **Form Handling:** React Hook Form
* **HTTP Client:** Axios
* **UI Components & Icons:** Lucide React, React Hot Toast

---

### ✨ Key Features

* **Full Master-Detail CRUD:** Create, Read, Update, and Delete person records seamlessly.
* **Form State Management:** Dynamic form population for edits and automated resets using `react-hook-form`.
* **Asynchronous API Integration:** Clean end-to-end communication with proper loading state indicators and error handling.
* **Interactive UI/UX:** Responsive layout with smooth navigation, animated notifications via `react-hot-toast`, and modal confirmation alerts for deletion.
